# Human-coding artifact status

The canonical artifact entry point is the repository-root `README.md`.

- `annotation_outputs/major_revision_blind_packet_20260615/evaluator_packet/`
  is the current 60-pair v1 stress-test package.
- `expert_validation_60pair_results_R17_20260607/` and its blind-review packet
  are superseded pilots and must not be used to reproduce manuscript numbers.
- `round2_candidate_pairs_20260616/` is exploratory pair construction.
- Every `round2_v2_CLEARER_synthetic_*` directory contains model-generated dry
  runs, not human annotations.

The current paper reports the packet-integrity sensitivity analysis in
`manuscript/supplement/validation_sensitivity_results.csv`; it does not treat
the v1 study as independent external validation.
