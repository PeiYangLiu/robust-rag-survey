# Candidate Set R17

This is a provenance-blinded packet for validation review. Direct source metadata, operational logs, runtime files, and non-content timing fields are withheld by the coordinator.

Files:
- `participant_responses.csv`: blinded reviewer annotations.
- `gold_adjudications.csv`: blinded adjudicator annotations.
- `gold_panel_consensus.csv`: panel-level consensus labels.
- `expert_validation_60pair_summary.json`: aggregate agreement/count summary.
- `gold_agreement_summary.json`: gold-panel agreement summary.

The source key is maintained separately by the coordinator and should not be shared with reviewers during blind validation.
